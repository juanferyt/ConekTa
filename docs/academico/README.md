# Entrega académica de ConekTa

Este expediente describe un prototipo académico. No acredita efectividad en contratación ni validación estadística. Fecha de preparación: 15 de octubre de 2026.

## Documentos

1. [Alcance y requisitos](requisitos.md): objetivos propuestos, criterios de aceptación y trazabilidad.
2. [Diseño y diagramas](diagramas.md): arquitectura, modelo central y secuencia principal.
3. [Matching](matching.md): decisiones, fórmula, ejemplos y límites.
4. [Evaluación con usuarios](evaluacion-usuarios.md): protocolo listo para aplicar.
5. [Registro de sesiones](registro-sesiones.csv): plantilla vacía; no contiene resultados simulados.
6. [Verificación técnica](verificacion.md): resultados observados y pendientes.

Los objetivos y requisitos son una propuesta reconstruida desde el software existente. Deben contrastarse con la rúbrica de la asignatura. No se atribuyen entrevistas, encuestas ni decisiones históricas que no estén documentadas.

## Secuencia de entrega

- Revisar los requisitos con el docente y fijar el alcance.
- Presentar el cálculo manual del matching junto a su prueba automatizada.
- Ejecutar la demostración del README raíz con datos ficticios.
- Aplicar el protocolo con participantes voluntarios, registrar resultados y corregir los problemas observados.
- Redactar conclusiones por objetivo, incluyendo lo que quedó sin validar.

Las encuestas y sesiones requieren participantes reales. Hasta realizarlas, la evaluación de usabilidad y utilidad permanece pendiente.
